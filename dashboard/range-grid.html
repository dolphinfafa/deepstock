GRID

Range Grid

仅在震荡状态中运行、以库存上限为核心的 SPY 网格模块

策略思想

Range Grid 只在 ARC 判定为 Range 的交易日请求运行。它以 50 日价格锚点与 20 日波动率确定网格间距，分为四级库存，最大风险资产暴露为 40%，其余资金停留在 SHY。单日异常波动超过固定阈值时立即退出风险库存。

该模块被定义为回撤控制工具，而非替代股票趋势暴露的收益引擎。

模块回测结果
